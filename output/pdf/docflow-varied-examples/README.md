# Новые примеры для Docflow Hub

Все организации, реквизиты и операции вымышлены. Это новые синтетические документы, а не повтор прежнего датасета. Загружайте в приложение PDF и PNG; README и JSON предназначены для сравнения результатов.

| Файл | Тип | На что обратить внимание |
| --- | --- | --- |
| 01-invoice-mistral-paperworks.pdf | Счёт | GBP, 3 позиции, subtotal 1350.00, VAT 270.00, total 1620.00 |
| 02-bank-statement-lantern-quay.pdf | Выписка | 8 операций, ведущие нули в номере счёта и reference, EUR; opening 8500.00, credit 7130.75, debit 4172.30, closing 11458.45 |
| 03-contract-orbit-archive.pdf | Договор | 2 страницы; общая сумма 12000.00 EUR и сроки находятся на второй странице; этапы оплаты не следует принимать за общую сумму |
| 04-tax-letter-northbridge.pdf | Налоговое уведомление | Amount due 312.45; assessed charge 420.00 и credit 107.55 являются другими величинами; срок оплаты 2026-10-10 |
| 05-invoice-mistral-paperworks-scan.png | Скан счёта | Тот же счёт в виде изображения без текстового слоя: сравните распознавание с PDF |

Полный эталон значений находится в expected-values.json. Он описывает содержание исходных документов, а не обещанный ответ модели. Для чисел указаны нормализованные значения.

Сначала проверьте классификацию, затем поля, таблицы и привязку к источнику. Для скана может сохраняться предупреждение о необходимости ручной проверки OCR. Автоматическая обработка этих новых файлов в приложении ещё не запускалась.
